Este código HTML define um iframe com foco total em segurança e privacidade para carregar uma página interna.

Abaixo está o que cada parte significa:

  • src="aula1.3.1_tornando_iframe_seguros.html": Define o arquivo local que será carregado dentro do quadro.
  • referrerpolicy="no-referrer": É uma medida de privacidade. Ela instrui o navegador a não enviar nenhuma informação de referência (o endereço da página principal) para a página que está sendo carregada dentro do iframe.
  • sandbox="sandbox": Ativa o nível máximo de restrição de segurança (caixa de areia). Ao usar apenas a palavra-chave sandbox (ou sandbox=""), o navegador bloqueia quase tudo dentro do iframe, incluindo:
    • Execução de scripts (JavaScript).
    • Envio de formulários.
    • Acesso a cookies e armazenamento local.
    • Abertura de janelas pop-up.
  • frameborder="0": Remove a borda padrão do quadro para que ele se integre visualmente à página sem linhas divisórias. No entanto, não utilize esse atributo. Recomendamos que utilize o CSS para obter o mesmo efito.

Resumo do comportamento

O conteúdo será exibido de forma estática e isolada. Como o sandbox está activado sem permissões extras (como allow-scripts), qualquer código interativo no arquivo aula1.3.1_tornando_iframe_seguros.html não funcionará.
