Navegação no Iframe

A navegação em um <iframe> HTML é realizada vinculando links (<a>) ao atributo name do iframe usando o atributo target. Isso permite carregar diferentes páginas ou conteúdos externos (vídeos, mapas) dentro de uma área específica da página principal, mantendo a estrutura fixa. CSS é usado para estilizar o iframe, definindo tamanho, bordas e responsividade.

Como Criar Navegação em Iframe (Passo a Passo)

  1. Defina o Iframe: Crie um <iframe> com um nome único no HTML.

No HTML

<iframe name="meuFrame" src="paginas/pagina1.html" width="100%" height="300px"></iframe>

  1. Crie os Links: Utilize a tag com o atributo target apontando para o nome do iframe.

<a href="paginas/pagina1.html" target="meuFrame">Página 1</a>
<a href="paginas/pagina2.html" target="meuFrame">Página 2</a>

Resultado:

  • Página 1
  • Página 2

Dicas de CSS para Iframe

  • Responsividade: Utilize width: 100% e height: auto (ou vh) para ajustar ao tamanho da tela.
  • Estilização: Remova bordas ou adicione estilos personalizados:
No CSS

iframe {
border: 2px solid #ccc;
border-radius: 8px;
}

Considerações Importantes

  • Conteúdo Externo: O <iframe> é ideal para incorporar componentes de terceiros como mapas e vídeos.
  • Segurança: Use o atributo sandbox no iframe para restringir permissões de scripts ou formulários, se necessário.
  • Alternativas: Para navegação interna, a estruturação com links internos (IDs) também pode ser utilizada.
